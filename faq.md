# Частые вопросы

## Это обычный табличный Kaggle-контест?

Это RL-контест, адаптированный под автоматический Kaggle leaderboard. Для
leaderboard участник отправляет CSV с действиями, а код обучения и модель можно
прикладывать отдельно для воспроизводимости.

## Можно ли использовать предобученные веса для Breakout?

Нет. Предобученные веса и чужие готовые checkpoint'ы для Breakout запрещены.

## Можно ли загружать веса, которые я обучил сам во время контеста?

Да, если вы обучили их сами и не нарушили правила контеста.

## Обязательно ли использовать предоставленные обертки?

Чтобы не было расхождений с проверкой, ориентируйтесь на официальную фабрику
среды из `env/make_env.py`.

## Может ли моя отправка использовать интернет?

Нет. Проверка предполагает работу без доступа к интернету.

## Как нужно оформлять отправку?

Для leaderboard нужно отправить `submission.csv` с колонками `id` и `action`.
Файл модели можно приложить отдельно, если это требуется правилами курса, но
автоматическая метрика Kaggle использует только CSV.
