# Пространство действий

Официальная среда использует минимальный набор действий из `ALE/Breakout-v5`.

Допустимые целочисленные действия:

- `0`: `NOOP`
- `1`: `FIRE`
- `2`: `RIGHT`
- `3`: `LEFT`

Метод `Agent.act(observation)` должен возвращать целое число из этого диапазона.

При недопустимом действии проверка завершится ошибкой.
