# Правила оценки

Для каждой отправки действия из `submission.csv` проигрываются на `K` скрытых
seed'ах. Каждый seed соответствует одному полному эпизоду Breakout в среде
`ALE/Breakout-v5`.

Пусть `R_i` обозначает итоговый счет, полученный в эпизоде `i`. Тогда итоговая
метрика вычисляется так:

```text
Final Score = (1 / K) * sum_i R_i
```

## Лидерборды

- Public leaderboard: считается на одной скрытой части данных.
- Private leaderboard: считается на другой скрытой части данных и определяет
  итоговый результат.

## Что важно

- высокий средний счет,
- устойчивость на разных seed'ах,
- воспроизводимость,
- соответствие CSV-формату отправки.
