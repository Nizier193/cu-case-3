# Официальная спецификация среды

## Среда

- Идентификатор Gymnasium: `ALE/Breakout-v5`
- Пространство действий: минимальный набор действий
- Счет за эпизод: суммарная награда эпизода без изменений со стороны среды

## Формат наблюдения

Официальный стартовый код передает наблюдения после стандартной предобработки Atari:

- оттенки серого,
- размер `84 x 84`,
- стек из 4 кадров,
- тип данных `uint8`,
- форма тензора `(4, 84, 84)`.

Это делает настройку проверки стабильной, но оставляет участнику свободу в
выборе метода обучения.

## Предобработка по умолчанию

В файле `make_env.py` используется следующее:

- `frameskip=1` в исходной среде ALE,
- `frame_skip=4` внутри `AtariPreprocessing`,
- `screen_size=84`,
- `terminal_on_life_loss=False`,
- `grayscale_obs=True`,
- `full_action_space=False`.

## Правила проверки

- Для проверки используются скрытые seed'ы.
- Каждый seed соответствует одному полному эпизоду.
- Итоговая метрика считается как средний счет по всем эпизодам проверки.
- Обрезка награды во время проверки отключена.

## Требования к CSV-отправке

Во время автоматической проверки Kaggle берет действия из `submission.csv`.
Файл должен содержать колонки:

```csv
id,action
```

Колонка `action` должна содержать целые числа из официального пространства
действий.

Python-файл агента можно использовать для обучения и локальной генерации
действий, но leaderboard оценивает именно CSV.
