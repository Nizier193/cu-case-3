# Пример формата отправки

Для автоматического Kaggle leaderboard отправляется CSV-файл с действиями:

```csv
id,action
public_000_00000,1
public_000_00001,2
public_000_00002,2
```

Колонки:

- `id`: идентификатор шага из `sample_submission.csv`;
- `action`: действие агента на этом шаге.

Допустимые действия:

- `0`: `NOOP`
- `1`: `FIRE`
- `2`: `RIGHT`
- `3`: `LEFT`

Файл модели можно приложить отдельно для воспроизводимости, если это требуется
правилами курса, но автоматическая Kaggle-метрика использует только CSV с
действиями.

Пример файла лежит в `examples/sample_action_submission.csv`.
